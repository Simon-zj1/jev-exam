# 品牌与图标

## 图标在说什么

图标不是装饰性的字母或盾牌，它是这个产品的结构图：

```
  ▬▬▬▬▬▬   ●     左边三条横线 = 材料里的要点
  ▬▬▬▬       ○     长短不一，因为内容本身并不均等
  ▬▬▬        ◐     右边三个圆 = 一次判定的三种结果
```

**三条横线（材料要点）**

- 长度递减（312 / 248 / 196）：材料里的要点从来不是等长的，有的是一整句，有的只是半句。
- 它同时对应判定链路里的 `rubric_point`——简答题被拆成的正是这样一条条要点。

**三个圆（判定结果）**

| 形状 | 含义 | 对应产品里的东西 |
| --- | --- | --- |
| 实心 ● | 命中 | 某个得分点判到了 |
| 空心 ○ | 未命中 | 某个得分点没说到 |
| 半实心 ◐ | 待复核 | 判定强度不足，如实标出来，不计入掌握度 |

第三个圆是刻意放进去的：**「不确定」是这个产品的第一公民**，不是异常状态。
大多数打分工具只画前两个圆，图标里保留第三个，是在提醒自己别把它做成一个假装确定的分数。

## 配色

靛蓝 `#4B5BFF` → 青绿 `#17C2A4` 的对角渐变：蓝代表判定与理性，青绿代表学习与生长。
白色前景在两种主题下都保持可读，所以图标本身不随深浅色切换。

## 文件

| 文件 | 用途 |
| --- | --- |
| `docs/brand/icon.svg` | 源文件（1024×1024） |
| `src/app/icon.svg` | 浏览器标签页图标（Next.js 约定） |
| `src/app/apple-icon.png` | iOS 主屏图标（180×180） |
| `docs/brand/icon-512.png` / `icon-180.png` / `icon-32.png` | 导出尺寸 |
| `src/components/brand-mark.tsx` | 顶栏内联版本：跟着文字大小缩放，不用额外请求 |

## 改动约定

改图标时，`docs/brand/icon.svg`、`src/app/icon.svg` 与 `brand-mark.tsx` 三处要一起改，
它们必须是同一套几何；导出的 PNG 用 `sips` 从 SVG 重新生成。

### 形状 × 配色矩阵（第二版）

配色不该被一个渐变锁死，所以形状与配色拆成两个独立维度：

- [icon-palettes.html](icon-palettes.html)：4 个形状 × 6 套配色的矩阵，
  含 104px 应用图标尺寸与 32px / 18px 的真实使用尺寸，截图见 [icon-palettes.png](icon-palettes.png)。
- [candidates/](candidates/)：`<形状>-<配色>.svg`，例如 `eyedot-ink.svg`、`gap-paper.svg`，
  24 个组合各自可用。

| 配色 | 适合 | 代价 |
| --- | --- | --- |
| 墨 + 朱砂 Ink & Vermilion | 「点睛」这个名字的字面表达；文化感最强 | 深色底，浅色界面里需要描边或反白 |
| 宣纸 Rice Paper | 浅色界面、阅读场景、文科人群 | 在深色模式里必须换版本 |
| 靛蓝（扁平）Flat Indigo | 与现有页面主色一致，风险最小 | **单色无法表达「点睛」的两层结构，形状会退化成同心圆** |
| 松墨绿 Pine | 长时间学习不刺眼，沉稳 | 绿色在「完成/正确」语义上与状态色冲突 |
| 夜蓝 + 薄荷 Night & Mint | 深色模式原生 | 放进浅色界面会突兀 |
| 莫兰迪雾色 Mist | 柔和、有审美 | 小尺寸对比度最弱，18px 几乎看不清 |
