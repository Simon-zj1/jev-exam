# 命名分析：为什么不该叫「Jev 备考」

## 先说结论

**用一个你无法控制、且随时打算替换的第三方模型名，给产品命名，是最不该犯的一类错误。**

`Jev` 是 TypeSafe 的 System One 决策模型。而这个仓库里，
[src/lib/engine/](../../src/lib/engine/) 明确把它做成了可替换的一个实现
（`typesafe` / `llm-judge` / `lexical`），CHANGELOG 里还写着「自托管决策模型（Kev 等开源复刻）
作为 `DecisionEngine` 的第三种实现」。也就是说：

> 架构上「Jev 是可以被换掉的」，名字上「Jev 是产品的身份」。这两句话互相矛盾。

一旦换成 Kev、换成自研、换成下一代模型，名字就变成了一句假话——
而改名的成本远高于当初起个好名字的成本。

## 「Jev 备考」的四个具体问题

| 问题 | 具体表现 | 后果 |
| --- | --- | --- |
| **绑定供应商** | 名字里焊死了 TypeSafe 的模型 | 换引擎即改名；用户以为你在替 TypeSafe 打广告 |
| **读不出来** | 中文用户看到 `Jev` 不确定读 /dʒev/ 还是 /jev/ | 口头传播变成「J-E-V，j-e-v」，传播成本高 |
| **场景锁死** | 「备考」把产品缩成考试工具 | 材料问答、复习排期、教师场景都被排除在外 |
| **搜不到你** | 「Jev」的搜索结果被 TypeSafe 与同名项目占据 | 做内容获客时，用户搜的是别人 |

## 好名字的五条硬标准

1. **不绑供应商**：名字要能活过三次引擎替换。
2. **念得出、写得对**：两到三个字，中文输入法一次选对，不用解释拼写。
3. **承载唯一卖点**：这个名字要能装下「逐点核对 / 清楚哪里没学会」，而不是「AI 学习」这种谁都能说的词。
4. **能画出来**：缩到 16px 还能认出的几何，而不是靠三个汉字撑。
5. **域名与商标可查**：这一条我查不了，必须你自己去查（`.com` / `.cn` + 商标网）。

## 五个候选

每个都写出它的缺点——只写优点的清单没有决策价值。

| 候选 | 英文 | 一句话含义 | 强在哪 | 弱在哪 |
| --- | --- | --- | --- | --- |
| **点睛** | Eyedot | 画龙点睛：缺的那一点才是关键 | 文科共鸣强；「点」双关得分点；成语自带解释力 | 已有同名机构；笔画多，图标必须抽象化 |
| **点石** | Touchstone | 点石成金；英文 touchstone = 试金石 | 中英双关都指向「检验」；动作感强（材料→考卷） | 叫「点石」的公司很多，重名概率高 |
| **拾遗** | Recall | 拾起你漏掉的要点 | 精准对应覆盖率与「待复核」这两个独有机制 | 字形要选字，输入体验差；Recall 在英文里太通用 |
| **对点** | Dotcheck | 逐点核对一遍 | 最直白，等于把功能写进名字；两字都好写 | 偏工具感，缺情绪；口语里另有含义 |
| **点阵** | Dotgrid | 最小单位是点，一屏就是一次判定 | 机制驱动，最接近字节跳动的命名思路 | 偏冷，不像给学习者用的产品 |

## 推荐

**首选：点睛（Eyedot）**，次选：**点石（Touchstone）**。

选「点睛」的理由：目标用户是文科备考人群，成语自带记忆点与解释力；
它说出的正是这个产品的核心主张——**重要的不是总分，是缺的那一点**。
图标可以直接画「整体里被点亮的一个点」（见 `candidates/a-eyedot.svg`），
小尺寸下也不会糊。

选「点石」的理由：如果你更在意简历与英文材料，`Touchstone` 是真正的英文词
（试金石 = 检验标准），一句话能说清：「Touchstone grades every point of your own material」。

**不推荐**：任何包含 `AI`、`智能`、`学习`、`考试` 的名字。
这些词既不能说明你和别人的差别，也会随着「AI」这个词贬值而一起贬值。

## 改名的实际成本（很低）

产品名在代码里只有**一个真源**：

- [src/lib/config.ts](../../src/lib/config.ts) 的 `APP_NAME` / `APP_TAGLINE` —— 界面标题、manifest、
  离线页都从这里取。
- 少量字面量：`src/lib/services/export.ts`（导出文件名）、`src/app/icon.svg`（无障碍标签）。
- 文档与 README 的标题、`docs/brand/icon.svg` 的 aria-label。

**不需要改**：`Jev` 作为引擎名出现在 `src/lib/engine/typesafe.ts`、能力对比文案与 CHANGELOG 里，
那些地方说的就是 TypeSafe 的模型，应该保留。产品名与引擎名分开之后，
「引擎可替换」这件事才在命名上也成立。

## 待办（需要你决定）

2. 查域名与商标——这一步只能你来。
3. 定了之后我做三件事：改 `APP_NAME`、按新名字重做图标主稿、同步 README / 网站 / 简历描述。
